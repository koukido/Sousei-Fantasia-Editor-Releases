# 在编辑器中检查场景

[指南目录](README.md) · [English](../en/editor-workflow.md) · [日本語](../ja/editor-workflow.md)

资源管理器用于查找文件，层级用于查找场景对象，对象详情用于编辑所选对象的组件。多个对象可以引用同一份资源，删除一个对象与删除资源文件是不同操作。

## 检查 Scene Lab

1. 打开 `Menu.sfscene`，在层级选择 `Controller`，确认 `HelloScene.cs` 已挂载且启用。
2. 运行测试，检查运行时创建的对象。
3. 将渲染工作区在游戏编辑与 UI 编辑之间切换。UI 编辑会显示画布选择、排列等工具，不代表把正在运行的游戏切换到另一个场景。
4. 编辑其他已保存场景前，先停止测试。停止会恢复编辑数据，不会自动把模拟结果保存回场景。

## 选择观察相机

编辑器相机与游戏相机相互独立。关闭游戏相机联动时，移动编辑器相机只改变检查角度；开启联动时，可检查当前游戏相机的构图。场景名称相同但画面不同，可能只是两个相机朝向不同。

停靠的渲染子窗体与游戏窗口也有各自的大小。调整子窗体改变的是编辑器视口。项目可以采用 `1280 × 720` 等 UI 参考尺寸，再适配实际输出。不要直接拿另一种客户区尺寸截图中的坐标处理鼠标命中。

## 检查场景变化

完成[场景加载](scenes.md)练习后，进入 Arena，对照游戏窗口与编辑器。层级应跟随当前运行场景，游戏/UI 编辑模式保持你的选择。如果层级已经变化但视口空白，分别检查相机联动、所选相机与渲染器是否暂停，不要反复重新加载同一场景。

项目脚本也可能影响编辑器观察。使用了编辑器桥接代码时，检查它是否暂停预览或强制切换工作区；项目钩子同样可能让正常运行的场景看起来像是卡住。
