# UIとマテリアルを設定する

[ガイド一覧](README.md) · [English](../en/ui-and-materials.md) · [简体中文](../zh-CN/ui-and-materials.md)

Scene Labの[HelloScene.cs](../examples/HelloScene.cs)でキャンバス、暗いパネル、文字を作ります。Canvasは基準サイズ、Panelは背景とのコントラスト、Textはメッセージを担当します。

## 読みやすい文字を作る

文字色と背景色を明示的に設定します。対応するコントロールでは通常・無効・選択・ホバーをそれぞれ確認してください。ホバー時だけ読めても、未選択の枠や通常の文字が見えない問題は解決しません。

`UI_Text`はテクスチャを非同期に生成します。内容やレイアウトの変更で再準備が必要になります。同じ文字列を毎フレーム設定しても、カウンターの動きは改善しません。新しい内容の準備中は古い描画可能な結果を保持できるため、「テクスチャが存在する」と「最新の文字が準備済み」は別です。更新されない場合は`Is_Preparing`と`Last_Error`を確認します。

プロジェクトを移動する際は生成済み文字リソースも保持します。対象機にあるフォント、または同梱のフォールバックを使い、実際の言語の字形を確認してください。基本ラテン文字の事前準備だけで、日本語組版や中国語も準備済みになるわけではありません。

## 表示する前に画面全体を準備する

地区選択では、地図と一緒に見出し、地区ボタン、選択地区の詳細、開始ボタンを準備します。最初の画面のコンポーネントを登録し、必要なリソースを準備できる状態にしておきます。地図を表示してから「1フレームに1ラベル」の別キューを始めず、実際のリソース準備を待って画面を開きます。

Scene Labの基準キャンバスは`1280 × 720`です。縦長・横長の出力を試し、見えているコントロールとポインター判定が一致するか確認します。入力座標には現在のクライアントサイズを使い、独立したゲームウィンドウにエディターパネルの寸法を使わないでください。

## マテリアルを割り当てる

モデルとテクスチャを`Resources`へ取り込み、モデルを配置してオブジェクト詳細でマテリアルを設定します。メッシュ、テクスチャ、シェーダーはプロジェクト相対パスにします。他端末の絶対パスを参照しているマテリアルは、モデルだけコピーしても移植可能にはなりません。

Blenderのマテリアルが実行時に自動で同じ表示になるとは限りません。対応するシェーダー入力で意図した表面を構成し、透明度、カリング、深度書き込みをゲーム出力で確認します。ガラスが誤って深度を書き、別の面を隠している場合、不透明度を上げても順序の問題は直りません。

細線のジャギーを調べるときは、形状の輪郭、テクスチャの縮小、シェーダー生成の模様を分けて考えます。プロジェクトで使えるアンチエイリアス方式を選び、必要な方式をエクスポートにも含めます。アンチエイリアスは素材の欠落や未対応のマテリアル機能を補いません。方式とパッケージの既存仕様はリリース文書の`AntiAliasing-1.0.23.txt`を参照してください。
