# 最初のプロジェクトを作成する

[ガイド一覧](README.md) · [English](../en/getting-started.md) · [简体中文](../zh-CN/getting-started.md)

独立した **Scene Lab** プロジェクトを作り、1つのコンポーネントでメッセージを表示します。Windows x64版の1.0.31エディターを使います。C#とネイティブC++では必要なビルド環境が異なり、このC#の練習のためだけにVisual Studioを導入する必要はありません。

C#のコンパイルには、`net8.0-windows`のデスクトッププロジェクトをビルドできる[Windows x64 .NET SDK](https://dotnet.microsoft.com/en-us/download/dotnet)が必要です。エディターの実行環境や.NET Runtimeだけではコンパイルできません。新しいターミナルで`dotnet --list-sdks`を実行し、SDKが表示されることを確認します。`dotnet`をPATHに登録し、インストール中に開いていたエディターは再起動してください。Microsoftの[SDKとサポートの説明](https://learn.microsoft.com/en-us/dotnet/core/releases-and-support)も参照できます。新しいSDKで以前のフレームワークを対象にできますが、そのフレームワークのサポート期間が延びるわけではありません。

## インストールしてプロジェクトを作成する

1. [1.0.31のリリースページ](https://github.com/koukido/Sousei-Fantasia-Editor-Releases/releases/tag/v1.0.31)から完全版Setupと`SHA256SUMS.txt`を取得します。実行前にSetupのSHA-256を対応する行と照合します。
2. Setupを実行し、言語一覧で日本語を選びます。プロジェクトとは別の場所にエンジンをインストールします。ソフトウェアは未署名であり、ハッシュは電子署名の代わりにはなりません。
3. エディターを起動します。プロジェクト入口ウィンドウの名前欄に`SceneLab`と入力し、「プロジェクトを新規作成…」から空の保存先を選びます。別のプロジェクトが開いている場合は入口を開き直し、現在の内容を消去する機能は使わないでください。
4. 生成された`.souseiproject`とデータフォルダーを一緒に保存します。次回はこの入口ファイルを開きます。プロジェクトの素材をエンジンのインストール先へコピーする必要はありません。

開発機から配布サイトに接続できない場合は、取得できる端末から同一の公式Setupとチェックサムを渡せます。端末ごとのTokenは不要です。未検証のミラーへ置き換えないでください。

## メッセージを表示する

1. 外部からサンプルを追加する前にプロジェクトを閉じます。[Menu.sfscene](../examples/Menu.sfscene)を`Resources/Scenes`へ、[HelloScene.cs](../examples/HelloScene.cs)を`Resources/Scripts`へ保存します。拡張子と名前を保ち、GitHubのHTMLではなく元ファイルを取得してください。Scene Lab用の新規ファイルとして追加し、既存の作品を上書きしないでください。
2. プロジェクトを開き直し、リソース管理で`Menu.sfscene`をダブルクリックします。このファイルには画面UI用のカメラが設定されています。
3. 階層に`Controller`という空のオブジェクトを作ります。選択し、インスペクターで`HelloScene.cs`をC#コンポーネントとして追加します。`Message`は初期値のままにし、プロジェクトを保存します。
4. プロジェクト設定のシーンフローを開き、「開始シーン」を`Scenes/Menu.sfscene`に変更して適用します。テストはこの設定を使い、最後に表示したシーンから始まるとは限りません。
5. テストメニューから実行し、コンパイルと初期化を待ちます。ゲームウィンドウの暗いパネルに **Scene Lab is running** と表示されます。
6. テストを停止します。スクリプトが作ったオブジェクトは実行時のものであり、編集したシーンの保存を代替するものではありません。

コンパイルに失敗したら、エラーに表示されたビルドログを開きます。成功しても表示されない場合は、コンポーネントが有効か、ゲームのテストウィンドウを見ているかを確認します。[トラブルシューティング](troubleshooting.md)も参照してください。

## プロジェクトのファイル

`Resources`にはシーン、スクリプト、インポートした素材を、`Settings`にはプロジェクト設定を保存します。`.Sousei`にはローカルキャッシュ、ビルド、診断が入ります。生成済み文字テクスチャが`Resources/Generated`にある場合もあるため、読み込み問題への対処としてGeneratedという名前のフォルダーをすべて削除しないでください。

構成を変更する前にプロジェクト全体をバックアップします。`.souseiproject`だけを保存しても、参照先のリソースはバックアップされません。

次は[エディターの操作](editor-workflow.md)、続いて[2つ目のシーンの準備](scenes.md)へ進みます。
