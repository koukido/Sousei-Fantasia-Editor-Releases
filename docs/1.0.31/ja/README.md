# Sousei-Fantasia 開発者ガイド

対象バージョン **1.0.31** · [English](../en/README.md) · [简体中文](../zh-CN/README.md)

小さなプロジェクトを作り、コンポーネントの追加、別シーンの読み込み、ゲームの書き出しまで進めます。各章では、外部の美術素材を必要としない2シーン構成の **Scene Lab** を使います。順番に学ぶことも、作業に合わせて章を選ぶこともできます。

| 作業 | ガイド |
| --- | --- |
| エディターを導入し、最初のコンポーネントを実行する | [はじめに](getting-started.md) |
| オブジェクトを探し、エディターとゲームのカメラを使い分ける | [エディターの操作](editor-workflow.md) |
| C#コンポーネントとネイティブビルド環境を設定する | [コンポーネント](components.md) |
| 次のシーンを準備し、切り替えや合成を行う | [シーンの読み込み](scenes.md) |
| 読みやすい文字を作り、マテリアルを設定する | [UIとマテリアル](ui-and-materials.md) |
| 止まった映像とコンポーネントの動作を照合する | [録画と診断](recording.md) |
| エディターなしで起動するゲームを書き出す | [ゲームの書き出し](exporting.md) |
| コンパイル失敗、表示欠落、不完全な録画を調べる | [トラブルシューティング](troubleshooting.md) |

## ダウンロードとサンプル

[1.0.31のリリースページ](https://github.com/koukido/Sousei-Fantasia-Editor-Releases/releases/tag/v1.0.31)から完全版Setupと`SHA256SUMS.txt`を取得します。保守ツール単体ではエディターをインストールできません。

[サンプルスクリプト](../examples)は学習用の小さな例であり、完成したゲームではありません。各手順に従って自分のプロジェクトへコピーしてください。非公開プロジェクトやエンジンの内部実装には依存しません。

このガイドは操作方法を説明します。リリースの`AI-Handoff`は過去の移行記録です。旧連携を更新する際に参照し、入門手順とは分けて使ってください。
